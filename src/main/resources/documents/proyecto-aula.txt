Resumen General

El proyecto GAV (Gestión Asignación Viajes) busca desarrollar un aplicativo web integral para optimizar la gestión de transporte en hoteles de Cartagena, enfocándose en la asignación de conductores, rutas y viajes. Surge como respuesta a problemas de planificación manual, retrasos, duplicidad de rutas, mala gestión administrativa y pérdida de eficiencia operativa.

1. Problema identificado

Actualmente, la gestión manual del transporte en hoteles presenta dificultades como:

Asignación ineficiente de rutas.
Cruce de horarios.
Retrasos en traslados.
Falta de control en pagos y registros.
Mala utilización de vehículos y conductores.
Pérdida de clientes por baja calidad del servicio.

Esto afecta directamente la experiencia del usuario, los costos operativos y la productividad.

2. Solución propuesta

Se plantea desarrollar una plataforma web que permita:

Registrar conductores, clientes y viajes.
Asignar rutas automáticamente.
Monitorear viajes en tiempo real.
Mejorar la trazabilidad del servicio.
Reducir errores humanos.
Optimizar decisiones mediante análisis de datos.
3. Tecnologías del proyecto

El sistema contempla el uso de:

Backend: Spring Boot
Base de datos: MongoDB / PostgreSQL
Frontend web moderno
APIs de mapas y geolocalización
Servicios en la nube
Dashboard en Power BI
Modelo de optimización matemática
Integración de IA / LLM
Posible minería de datos y predicción de rutas

Desarrollar un aplicativo web que optimice la gestión y asignación de conductores y rutas en hoteles de Cartagena, mejorando eficiencia operativa, disminuyendo errores y aumentando la satisfacción del usuario.
